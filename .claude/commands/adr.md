# /adr

1. Найти максимальный номер в `docs/adr/`, взять следующий.
2. Заполнить по шаблону `docs/adr/0000-template.md`, файл назвать `NNNN-краткое-название.md`.
3. Спросить у меня то, чего не знаешь из контекста: что вынудило решать, какие
   варианты рассматривались, какую цену платим.
4. Секция «Альтернативы» обязательна и не может быть пустой. ADR без отвергнутых
   вариантов означает, что выбора не было — тогда это не решение, а факт,
   и ADR не нужен.
5. Секция «Последствия» обязана содержать минусы. Решение без минусов не бывает.
