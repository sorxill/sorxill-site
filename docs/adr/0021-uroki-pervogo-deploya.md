# ADR-0021: правила проверки, выведенные из первого деплоя

**Дата:** 2026-07-31 · **Статус:** принято

## Контекст

Первый деплой занял около двадцати итераций. Ни одна не была связана с бизнес-логикой:
все падения приходились на упаковку, конфигурацию контейнеров и маршрутизацию.
Список — в `CLAUDE.md`, раздел «Грабли».

Общая причина у большинства одна: **проверка выполнялась не в той среде, где
код будет работать.** Тесты зеленели в окружении, где нужный пакет был установлен
руками ранее; health-check писался в синтаксисе GNU для образа с busybox;
упаковка проверялась editable-установкой, которая подменяет пути импорта.

## Решение

Правило: **проверка обязана воспроизводить целевую среду, а не приближать её.**
Конкретно, до коммита:

| Изменение | Обязательная проверка |
|---|---|
| `pyproject.toml`, зависимости | `pip install -e ".[dev]"` в **чистом** venv |
| `Dockerfile`, упаковка | сборка колеса + импорт **вне** каталога исходников |
| health-check, скрипты в Alpine | только синтаксис busybox |
| `package.json` | пересборка `package-lock.json` в том же коммите |
| ENV, конфиг | тест на разбор значения в том формате, в каком его отдаёт compose |

Там, где воспроизвести среду нельзя (Docker недоступен), это фиксируется как
известный пробел — см. `docs/STATUS.md`, пункт 6 — а не заменяется догадкой.

## Альтернативы

| Вариант | Почему не он |
|---|---|
| Просто быть внимательнее | Не работает: ошибки были не по невнимательности, а из-за неверной модели среды |
| Прогонять всё только в CI | Цикл обратной связи 3–10 минут вместо секунд, и сервер занят чужими ошибками |
| Локальный Docker для полной репликации | Правильно и когда-нибудь нужно, но недоступно в текущей среде разработки |

## Последствия

Проверки перед коммитом стали дольше — установка в чистый venv занимает
секунд сорок. Это дешевле одной итерации деплоя, которая стоит десять минут
и требует внимания человека.

Отдельный вывод, который стоит держать в голове: **зелёный CI не означает
рабочий прод.** CI проверяет код, а падало всё, что лежит между кодом
и работающим сервисом. Smoke-тест снаружи после деплоя — не формальность,
а единственная проверка, которая покрывает этот разрыв.
